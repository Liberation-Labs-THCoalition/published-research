# Character Profiles Are All You Need (the v6 report): withdrawn

> **Withdrawn, 2026-10-14.** The results in this report are withdrawn, and its conclusions, including the claim in its title, are not supported.
>
> In the Claude runs behind its LoCoMo figures, and in its LongMemEval run, the file given to the answering model held each question's gold answer beside the retrieved context. A model that can see the answer is not being tested on memory, and the answers indicate the gold was used. On LoCoMo, the reported run scored 0.92 on the 139 questions whose context held none of the answer's content words. On LongMemEval, at least six answers gave the gold answer exactly where the context held neither the answer nor what it is worked out from, such as a total of 1,998 views whose two parts appear nowhere in the context.
>
> For Mnemosyne on LongMemEval, see ["Whole Sessions, Not Passages"](../mnemosyne-longmemeval-v10/) (Mnemosyne v10), which was evaluated with blind inputs on pre-registered held-out questions. The report in this folder is left unchanged so that existing citations still resolve.
