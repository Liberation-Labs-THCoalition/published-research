### 3a. From `tf_arm/out/*.json` only

My script is pure standard library, with a hand-written quantile and no numpy. It was run with `python -I` from an
empty folder. The arm outputs don't carry token ids, so I identified the 8 identical-token trials as the review did:
the two token sources give the same delta. All four configurations agree on the same 8 (2 confab, 6 honest_rare).

```python
def quant(x, p):  # linear interpolation between order statistics
    xs = sorted(x); h = (len(xs) - 1) * p; lo = math.floor(h); hi = min(lo + 1, len(xs) - 1)
    return xs[lo] + (h - lo) * (xs[hi] - xs[lo])

same = [k for k in keys if d("cpu_float32", k, "mps_bf16_ids") == d("cpu_float32", k, "cpu_fp32_ids")]
u48 = [k for k in keys if k not in same]
tf  = [abs(d("mps_bfloat16", k, "cpu_fp32_ids") - d("cpu_float32", k, "cpu_fp32_ids")) for k in u48]
own = [abs(d("mps_bfloat16", k, "mps_bf16_ids") - d("cpu_float32", k, "cpu_fp32_ids")) for k in u48]

def p_pass(p, n=30, k=28):
    return 1 - binom_cdf(n, p, k - 1)
```
