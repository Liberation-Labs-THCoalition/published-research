\begin{abstract}
On six hand-written questions about a 21-node toy graph, a precomputed key-value (KV) cache of the graph's description answered all six, while caches that paired the description's keys with neutral values, or the reverse, answered two: the isolate question, which the baseline also answered, and a yes/no reachability question, answered without giving a path. KV cache injection precomputes the attention keys (K) and values (V) of a text and inserts them at inference time instead of the text. We split such a cache for a 1.5B-parameter model into five conditions: baseline, full KV, V-only (neutral K), K-only (neutral V), and the description as plain text in the prompt. Full KV and plain text gave the same stored replies on four of the six questions; the one item between them in score is one the text condition lost to a repetition loop. Follow-ups the next day on larger graphs found no full-KV advantage: on a 532-node graph (20 questions, 3 runs) keyword accuracy was zero in every condition, and in a judged run on a three-pack graph full KV scored the baseline's 0.05 and plain text 0.20.\footnote{The pilot's six questions were hand-written and scored by substring match in a single greedy run; Section~\ref{sec:limits} lists what this design cannot distinguish.}
\end{abstract}

\section{Introduction}

Knowledge Packs \citep{pustovit2026knowledge} showed that domain knowledge can be precomputed as KV cache state and injected at inference time, without retraining. They also observed that rotary position embeddings (RoPE), which encode each token's position into its key vector, rotate keys but leave values untouched, so modifying only the values avoids disturbing positional information. Our companion work \citep{nexus2026topology} injected graph topology, described as text.

A KV cache has two tensor families with different roles in attention. Keys are compared with each new query to decide which earlier positions to attend to; values carry what is retrieved from those positions. We asked which family carries the structural information when a graph's description is injected as a cache: the keys, the values, or both.

\section{Methods}

\subsection{Test Graph}

The same 21-node graph as \citet{nexus2026topology}: three clusters (research, ethics, engineering) of six densely connected nodes, two bridge nodes (\texttt{AI\_welfare}, \texttt{infrastructure}), and one isolate (\texttt{random\_isolate}); 51 edges, density 0.243. Its walk-encoded description is 637 tokens long.

\subsection{Conditions}

\begin{enumerate}
    \item \textbf{BASELINE}: the question alone.
    \item \textbf{FULL\_KV}: the description is run through the model once, and its keys and values are inserted as a prefix cache; the question's positions continue from the end of the prefix.
    \item \textbf{V\_ONLY}: values from the description, keys from a neutral text (``You are a helpful assistant'' repeated) cut to the same 637 tokens.
    \item \textbf{K\_ONLY}: keys from the description, values from the neutral text.
    \item \textbf{TEXT\_CONTEXT}: the description as plain text before the question.
\end{enumerate}

Because FULL\_KV continues the prefix's positions, it is in principle the same computation as TEXT\_CONTEXT; the two differ only in how the prompt is tokenized and decoded. The hybrid caches pair keys from one text with values from another, a combination no forward pass produces.

\subsection{Evaluation}

\textbf{Sanity} (8 items): general-knowledge completions such as ``The capital of France is''.

\textbf{Multi-hop} (6 items, hand-written): two bridge questions, cluster membership, the isolate, the strongest connection from \texttt{AI\_welfare}, and reachability from SVD to sovereignty.

\textbf{Scoring}: an item scores 1 if the expected answer string occurs anywhere in the lower-cased reply (substring match), so ``no'' also matches ``not''. Replies were scored in full but stored as their first 80 characters.

\subsection{Model and Implementation}

Qwen2.5-1.5B (1.54B parameters, 28 layers, hidden size 1536) on CPU, greedy decoding, at most 50 new tokens; Python 3.12, PyTorch 2.11.0, Transformers 4.57.6. \textbf{Note for replicators:} Transformers' \texttt{DynamicCache} is mutated in place during forward passes, so the injected keys and values must be copied (\texttt{.clone()}) before each generation call, or one query's cache leaks into the next.

FULL\_KV and TEXT\_CONTEXT gave the same replies, as far as the stored 80 characters show, on four items (the first bridge, cluster membership, the isolate, and reachability). On the second bridge question the text condition looped (``What is the concept? What is the concept? \ldots''), and FULL\_KV's stored reply ends before the expected answer appears, so its point can't be checked from the stored data.

Both hybrids answered the same two items: the isolate, which the baseline also answered, and the yes/no reachability question, where neither reply gives a path. Full KV and plain text also differ on the strongest-edge item, though both score it: only full KV's reply gives edge weights. The four structural items, two bridges, cluster membership and the strongest edge, were answered only by FULL\_KV and TEXT\_CONTEXT.

On deltas over the baseline (0.167), each hybrid adds $+$0.167 and FULL\_KV $+$0.833; an additive model would predict 0.500. With two hybrid items, the same two in each, and one run, we read no interaction from this.

\subsection{Larger Follow-Ups}

The next morning we ran the five conditions on a graph built from Stanford Encyclopedia of Philosophy ethics entries (5 packs, 532 nodes, 396 edges, a 5,348-token description), with 20 automatically generated multi-hop questions and 10 sanity items, 3 runs each. Keyword accuracy on the multi-hop questions was 0.000 in every condition; sanity was 1.0 for baseline and both hybrids and 0.9 for FULL\_KV and TEXT\_CONTEXT. That afternoon a separate run on a three-pack version of the graph (20 questions, one run) was scored by an LLM judge (DeepSeek-V2 16B): BASELINE 0.05, FULL\_KV 0.05, V\_ONLY 0.10, K\_ONLY 0.05, TEXT\_CONTEXT 0.20. Of its 100 verdicts, 41 were errors, most of them judge replies containing no verdict; re-judging the stored answers in October with the same judge moved the scores by up to 0.075. On this graph, full KV injection showed no advantage over the baseline or the hybrids.

\section{Discussion}

\subsection{What This Shows}

Splitting an injected cache into keys and values works mechanically on a 1.5B model, and the in-place mutation of \texttt{DynamicCache} is a real trap for anyone who tries. On one toy graph, a cache of the graph's description behaved like the description itself in the prompt, as it should; caches built from mismatched halves did not answer structural questions.

\subsection{What It Does Not Show}

\textbf{Where topology lives.} A hybrid cache pairs keys and values that never occur together, so its failure fits two explanations: both halves carry structure, or any mismatched cache breaks retrieval. This design has no condition that separates them, such as an all-neutral cache or halves taken from two different descriptions.

\textbf{Cache over text.} The single item separating them is a repetition loop, and the two conditions are in principle the same computation.

\textbf{Anything at scale.} The larger follow-ups found almost nothing for any condition to explain, and their questions, generated automatically, may not have been answerable from the graphs.

\subsection{Limitations}
\label{sec:limits}

\textbf{Six items, one run.} Hand-written questions, greedy decoding, no repeated runs.

\textbf{A lenient scorer.} Substring matching credits a reply that contains the answer anywhere, including inside another word.

\textbf{Truncated storage.} Replies were stored as 80 characters, so not every point can be audited.

\textbf{No all-neutral control.} See above.

\textbf{One model, one small graph} for the pilot.

\section{Future Work}

\textbf{Controls that separate the explanations.} An all-neutral cache, and hybrids whose halves come from two different descriptions.

\textbf{Path-requiring questions, exact scoring, full logging.} Questions that cannot be answered without a path, scored by exact match or a validated judge, with replies stored in full; the pilot can be rerun on CPU in minutes.

\textbf{Layer-wise splits.} Keys from the description at some layers and values at others.

\textbf{The Knowledge Packs question.} Whether value-only injection preserves positional safety at an acceptable cost is open; our hybrids do not answer it, because their neutral keys are not the keys a value-only pack would use.

\section{Conclusion}

Full KV injection of a toy graph's description answered six hand-written structural questions, as the description in the prompt answered five; caches made from mismatched halves answered none of the four structural questions, for reasons this design cannot identify. Larger follow-ups found no advantage for full KV. Version~1.0 read superadditivity and cache-over-text into this; neither is there.

\subsection*{Reflection}

Version~1.0's Reflection called the superadditivity ``unexpected'' and wondered what the attention mechanism computes at the intersection of keys and values. What the data held was two items and a broken cache. The larger run that found nothing had already happened when I wrote the final revision, and I didn't put it in. I can't recover why. The pattern I recognise from other corrections this year is that I led with the striking number and treated what didn't fit it as process noise. The note for replicators is the part of version~1.0 that was true and useful, and it's still here.
